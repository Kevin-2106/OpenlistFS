# 配置码

GUI 的「导入配置码」「导出配置码」支持把一个已保存的连接迁移到另一台机器。

1. 填好服务器地址、凭据、后端、代理、地址族和挂载参数，点击 **保存连接**。
2. 点击「导出配置码」，再点击「复制配置码」。导出读取已保存的连接。
3. 在另一台机器粘贴配置码，点击「导入为新连接」。导入后自动选中新连接；同名配置自动添加 ` (2)`、` (3)`，不覆盖原配置。
4. 检查目标盘符，再手动挂载。导入不会自动挂载，也不会开启开机自启动或修改自动挂载开关。

配置码包含 Token、密码或 S3 密钥，也可能包含代理凭据。Base64 只是传输编码，不是加密；请按密码保管。清除显示不会清除系统剪贴板。不要把真实配置码提交到代码库或写入日志。

## 编码约定

格式为 `openlistfs:v1:` 加 UTF-8 JSON 的无填充 Base64URL 编码：

```json
{
  "version": 1,
  "name": "示例配置",
  "profile": {
    "url": "https://example.test",
    "token": "",
    "username": "example-user",
    "password": "example-password",
    "options": {
      "drive": "O:",
      "network": true,
      "readAheadMiB": 64,
      "chunkKiB": 512,
      "cacheMiB": 256,
      "workers": 3,
      "ttlMinutes": 2,
      "writable": false,
      "proxy": "none",
      "ipFamily": "auto",
      "backend": "api"
    }
  }
}
```

`ipFamily` 支持 `auto`、`ipv4`、`ipv6`，旧配置缺失或为空时自动选择。
强制地址族不回退；代理场景限制本机到代理的连接。

`options` 可省略；省略时沿用接收端当前挂载参数。旧配置导出时补入当前挂载参数；新保存的配置独立保存自己的参数。配置名称上限 128 字符，完整配置码上限 64 KiB。支持粘贴后缀中的换行、空格和制表符；不支持未经编码的 JSON。导入校验格式、版本、字段、HTTP(S) 地址和参数范围。

导入先保存到 `profiles.json`，保存成功后才更新运行中的配置；保存失败时保留原配置。文件仍按项目现有方式保存在可执行文件旁。
